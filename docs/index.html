tokenix

Estimate how many tokens your prompt, file, or whole project will cost across popular LLMs — offline, instantly, no API keys.

GitHub · Releases · Changelog

Install

brew tap hasirciogluhq/tap
brew install tokenix

# or
go install github.com/hasirciogluhq/tokenix@latest

Use

tokenix --data "Hello, world"
tokenix --file prompt.txt
cat prompt.txt | tokenix --model gpt-4o
tokenix --dir . --include '*.go' --exclude '*_test.go,vendor'
tokenix --data "test" --model gpt-4o,claude-3.5-sonnet --format json

Flags

FlagDescription
-d, --dataRaw text input
-f, --filePath to a file
-D, --dirDirectory to scan recursively
-i, --includeOnly count files matching these globs
-x, --excludeSkip files/directories matching these globs
-m, --modelModel key, comma-separated list, or all
--formattext or json

Supported models

gpt-4o-mini, gpt-4o, claude-3.5-sonnet, claude-3-haiku, gemini-1.5-flash, gemini-1.5-pro

Estimates are heuristic (character and word based), not exact tokenizer output.
